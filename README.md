## What it does
Writes one original, hilariously useless superpower one-liner to `/output/entry.txt` — the power to hear houseplants' thoughts, ruined by the fact that all they do is scream about the watering can.

## How to run
```sh
node main.ts
```
Then read `/output/entry.txt`.
